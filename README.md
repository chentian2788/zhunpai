# Beatlock · 音乐节拍器

一个开箱即用的网页版音乐节拍器，主打「特别好用 + 轻付费」。

## 如何打开

直接双击 `metronome.html` 用任意现代浏览器（Chrome / Edge / Safari / 手机浏览器）打开即可，无需安装、无网络依赖、单文件即用。

手机端建议用浏览器「添加到主屏幕」，体验接近原生 App。

## 核心能力

- **精准节拍**：基于 Web Audio API 的 lookahead 调度器，提前小段时间计划发声，长期运行不漂移、不卡顿。
- **节拍可视化**：环形拍点 + 中央脉冲光圈，每拍高亮，重音（强拍）用黄色区分。
- **拍号**：2/4、3/4、4/4、6/8（免费）；5/4、7/8、9/8、12/8（PRO）。
- **细分**：四分、八分（免费）；三连音、十六分（PRO）。复合拍号自动计算重音位置。
- **音色**：古典木声、电子哔（免费）；木鱼、鼓点、鼓边、牛铃（PRO）。
- **速度**：40–220 BPM（免费）；20–300 BPM（PRO）。可 +/- 微调、拖动滑杆、**TAP 打拍**、双击速度数字直接输入。
- **强弱开关**：可关闭重音。
- **音量**：独立控制。
- **预设**：保存 / 载入你的组合（PRO，最多 5 个），数据存本地。
- **快捷键**：`空格` 播放暂停，`↑ / ↓` 调速，`T` 打拍。

## 轻付费设计

免费版已能满足基础稳定使用。高级功能通过一次买断（¥6）解锁，不做月租、不做广告。

界面中点击带锁标的功能即弹出购买表单，演示版可直接在页面内解锁（数据存于浏览器本地 `localStorage`）。

## 接真实支付（上架前）

当前购买为本地演示解锁。正式商业化时，把 `unlockPro()` 里的本地写入替换为真实购买回调即可：

- iOS / Android：接入 App Store 内购 / Google Play Billing，购买成功后回调 `unlockPro()`。
- 网页：接入微信支付 / Apple Pay / Stripe 等，服务端校验后返回成功再调用 `unlockPro()`。

付费与免费划分（可自行调整）在代码顶部的 `TIME_SIGS`、`SOUNDS`、`SUBS` 三个数组及 `clampTempo()` 中。

## 上架建议

如需发布到商店，可将 `metronome.html` 套壳为：

- **PWA**：加上 `manifest.json` 与 Service Worker，即可安装到主屏幕并离线使用（注意 SW 需要 HTTPS）。
- **App**：用 Capacitor / 原生 WebView 包装，封装为 Android / iOS 应用并接通内购。

节拍引擎与 UI 均为平台无关实现，可直接复用。
